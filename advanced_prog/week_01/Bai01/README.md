## Bài 1: Cài đặt môi trường trong cửa sổ dòng lệnh

### Cài đặt:
- Môi trường cài đặt: WSL2/Arch Linux
- Cài đặt qua dòng lệnh: `sudo pacman -S jdk25-openjdk`

### Chương trình HelloName
- Tạo *public class* trùng với tên file
- Tạo phương thức *main* là điểm bắt đầu chương trình
- Lưu tên vào biến để dễ dàng thay đổi (nếu cần)
- Dùng phương thức *prinln* để in ra
